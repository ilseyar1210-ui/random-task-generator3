## Описание

Random Task Generator — это графическое приложение на Python с библиотекой Tkinter для генерации случайных задач. Приложение помогает пользователю получить случайную задачу из списка (учёба, спорт, работа), добавить свои задачи, сохранить историю и фильтровать её по типу.

## Установка и запуск

1. Убедитесь, что установлен Python 3.7 или выше.
2. Скачайте файл `main.py` из репозитория.
3. Откройте терминал в папке с файлом и выполните:
   ```bash
   python main.py
